# Publication figures

Drop the figure/thumbnail image for each paper in this folder, then reference
it from that paper's front matter in `_publications/`, e.g.:

```yaml
header:
  teaser: "publications/sharp.png"   # small thumbnail shown on the /publications/ list
  image:  "publications/sharp.png"   # (optional) banner shown at the top of this paper's own page
```

- `teaser` shows a small thumbnail next to the entry on the `/publications/` list page.
- `image` (optional) shows a full-width banner at the top of that paper's own page.
- Both can point to the same file, or different ones (e.g. a cropped thumbnail vs. a full figure).
- Recommended: roughly square or 4:3 images, a few hundred pixels wide, work best as thumbnails.
